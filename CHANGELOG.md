# Changes

## 0.1.0

The first release of Hermes Desktop, a native client for Hermes Agent on
macOS, Windows and Linux.

- Connect to Hermes on this computer or on another machine, with an API key
  or your dashboard login; keep several instances and switch between them.
- Your chats grouped by agent, with search, pins, rename and delete; the
  sidebar and recent transcripts are cached, so the app opens at once.
- Streaming replies, with each reply's tool calls folded behind one line you
  can open.
- Approve or deny commands, and answer sudo, secret and clarifying
  questions, from cards in the chat; notifications when a reply finishes or
  needs you.
- Every Look & Feel setting from the design: canvas, accent, density, fonts,
  orbs, translucent sidebar, and a marble app icon in the colour you pick.
- Keyboard first: Cmd/Ctrl+1–9 to jump between chats (hold to see the
  numbers), N for a new chat, K to search, comma for settings, Esc to stop.
- Updates itself from GitHub releases: a version found as the app opens is
  offered on its own page, and one released while it runs downloads quietly.
